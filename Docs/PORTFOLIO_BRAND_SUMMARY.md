# Janadesh Portfolio Summary

## About Project

Curious about secure campus elections? Here you have it.

Janadesh is a full-stack web and Android voting platform built for controlled college elections such as student councils, clubs, departments, and campus committees. It turns the voting workflow into a structured digital process: students authenticate with OTP, browse eligible elections, select candidates, and submit a vote through a clean React interface.

The backend is built with Node.js, Express, TypeScript, and PostgreSQL, with schemas for users, elections, candidates, vote records, OTP tokens, refresh tokens, and audit logs. A Solidity and Hardhat blockchain layer validates core election rules such as election lifecycle control, double-vote prevention, and result gating.

The project is demo-ready for academic review, GitHub, and CV use. It shows practical product engineering across frontend UX, backend APIs, database design, mobile packaging with Capacitor, and smart-contract testing.

## App Description

Janadesh helps colleges run controlled digital elections with a simple and auditable voting flow. Voters can verify their identity, view eligible elections, inspect candidates, submit votes, and see results when an election is complete. The system combines a React frontend, Express API, PostgreSQL database, and Solidity contracts for voting-rule validation.
